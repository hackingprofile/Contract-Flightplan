# Contributing

1. Keep the deterministic core useful with providers disabled.
2. Do not advertise mapping operations or CLI commands that lack tests.
3. Sign off commits with DCO (`Signed-off-by`) when you contribute through a Git repository.
4. Synthetic fixtures only. No credentials in logs or reports.
5. Independent dry-run: `scripts/quickstart.ps1`, then `scripts/rehearse.ps1`. Local checksum check: `scripts/verify-local-release.ps1`. License notes: `docs/LICENSE-SCAN.md`.
